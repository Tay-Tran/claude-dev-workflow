# Changelog

Newest entry first. Add one entry every time work is shipped to main.

## Entry format

```markdown
## YYYY-MM-DD — short title

**Changes**
- What changed, in plain words, for the owner.

**Migrations**
- Database or data migrations to run (the owner runs them), or "none".

**Owner must do**
- Steps the owner has to take (settings, keys, manual checks), or "nothing".
```
